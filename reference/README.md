# Reference material

Source material the look is matched AGAINST. Nothing here ships in a build
and nothing here is generated by the repo's own tools.

It lives outside `assets/` on purpose. Everything under `assets/` is a
shipped asset the Asset Contract governs — it is validated for naming,
provenance, size and budget, and it is packed into the game. A reference
sheet is neither: it is an input to the work, it carries no provenance of
its own, and packing it would ship art the player never sees.

  * `hero/01_hero_perspective.png` — the maintainer's reference for the
    axolotl (supplied 2026-09-07). `tools/blender/make_axolotl.py` is
    matched to it: the large glossy eyes, the domed skull, the three bare
    gill stalks carrying feathered blades, the translucent tail fin and the
    pink blotching all trace to this image. It was chosen deliberately over
    a realistic-salamander reading; the reasoning is recorded in
    `assets/character/axolotl/provenance.json` and in REQ-041.
