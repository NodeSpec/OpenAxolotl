# Test Plan: REQ-002 - Regeneration and Capability Loss System

## Testing Objectives

**Requirement:** Regeneration and Capability Loss System
**Category:** functional
**Description:** Pillar 1, soft layer — the signature mechanic and the game's constant feedback loop. Damage does not deplete a health bar; it strips a CAPABILITY. Losing the tail reduces swim speed, losing a gill reduces boost duration, losing a leg reduces climb height. Each loss is presented with comedic pop-and-sparkle framing, never gruesome. Capability loss modulates difficulty by making the world harder to traverse, and NEVER by itself ends a run — that is exclusively the life layer's job. Regen stations restore lost capabilities and can additionally reconfigure the axolotl into temporary mutation loadouts, turning healing from a chore into a build-crafting moment. Capability state is restored at checkpoints alongside lives.

## Acceptance Criteria

Criterion text lives HERE once; every section below cites the AC id.

- **AC-REQ-002-1** [automated] [PENDING] Damage from enemies and non-catastrophic hazards strips a specific capability rather than reducing a health value
- **AC-REQ-002-2** [automated] [PENDING] Each capability loss applies a defined, measurable movement modifier: tail reduces swim speed, gill reduces boost duration, leg reduces climb height
- **AC-REQ-002-3** [automated] [PENDING] Capability loss alone never triggers a life loss, a death, or a run reset under any combination of losses
- **AC-REQ-002-4** [automated] [PENDING] Regen stations restore all lost capabilities on use
- **AC-REQ-002-5** [automated] [PENDING] Regen stations can apply a temporary mutation loadout that alters the axolotl configuration for the duration given by tuning key regen.mutation.duration_s, after which the axolotl reverts to its base configuration
- **AC-REQ-002-6** [automated] [PENDING] Capability state is fully restored when the player respawns at a checkpoint
- **AC-REQ-002-7** [manual] [PENDING] Each loss and regrowth plays comedic, non-gruesome feedback consistent with the family-appropriate tone
