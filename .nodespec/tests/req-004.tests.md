# Test Plan: REQ-004 - Gill Mod Ability System

## Testing Objectives

**Requirement:** Gill Mod Ability System
**Category:** functional
**Description:** The collectible ability layer, built on the axolotl's visually iconic external gills. THREE Gill Mods ship at MVP — depth per power beats breadth of roster: BUBBLE GILLS produce bounceable bubbles for traversal, JET GILLS give a water dash for speed and combat, GLOW GILLS illuminate caves and activate bioluminescent objects for exploration. Electric, Frost, and Giant Gills are explicitly post-MVP and serve double duty as the first official post-launch content AND the reference example of what a well-built community-contributed Gill Mod looks like. The system must therefore be an extensible ability framework with a documented registration interface, not three hardcoded special cases — a world declaring a custom ability through the Level Contract plugs in here. Equipped Gill Mods interact with the capability layer: a lost gill shortens boost duration, and a Hookline Rig snag temporarily strips the equipped mod.

## Project Context

OpenAxolotl — Play it. Fork it. Build a world.

A colorful 3D action-platformer in Godot where a tiny axolotl explores strange aquatic worlds, restoring damaged habitats and rescuing creatures. Every world is a self-contained module anyone — human or AI coding agent — can fork, replace, or extend. Open source is a gameplay feature, not a line in the README.

## Acceptance Criteria

Criterion text lives HERE once; every section below cites the AC id.

- **AC-REQ-004-1** [automated] [PENDING] Bubble, Jet, and Glow Gill Mods are implemented, and each one unlocks at least one traversal or interaction affordance that is unavailable without it
- **AC-REQ-004-2** [automated] [PENDING] Gill Mods are registered through a documented extension interface, and a fixture mod can be added without modifying any file in the ability system core
- **AC-REQ-004-3** [automated] [PENDING] A world can declare and supply a custom Gill Mod through the Level Contract optional custom-ability element
- **AC-REQ-004-4** [automated] [PENDING] Equipping and switching Gill Mods is available to the player and reflected on the axolotl visually
- **AC-REQ-004-5** [automated] [PENDING] Gill capability loss multiplies the equipped mod's boost duration by tuning key capability.gill_loss.boost_duration_multiplier
- **AC-REQ-004-6** [automated] [PENDING] A Hookline Rig snag removes the equipped mod for the window given by tuning key enemy.hookline.mod_strip_seconds, then restores it automatically
- **AC-REQ-004-7** [manual] [PENDING] Each of the three MVP Gill Mods is developed to real depth rather than existing as a shallow one-note gimmick
