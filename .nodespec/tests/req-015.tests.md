# Test Plan: REQ-015 - Compatible updates, save migrations and withdrawal

## Testing Objectives

**Requirement:** Compatible updates, save migrations and withdrawal
**Category:** technical
**Description:** Treat package versioning, pinned asset dependencies and saves as a lifecycle. Stable world identity survives releases; incompatible migrations are not attempted silently. Review & Release owns withdrawal decisions and dependency-impact review; Installation applies the resulting release status without silently destroying saves.

## Acceptance Criteria

Criterion text lives HERE once; every section below cites the AC id.

- **AC-REQ-015-1** [automated] [PENDING] Progress is isolated by stable world identity and save-schema version; one level cannot read or overwrite another level's save namespace.
- **AC-REQ-015-2** [automated] [PENDING] Updates declare compatibility/migration behavior; failed migrations retain the prior installation and recoverable save data.
- **AC-REQ-015-3** [automated] [PENDING] Removing a level preserves progress by default; irreversible progress deletion requires an explicit separate player action.
- **AC-REQ-015-4** [automated] [PENDING] Withdrawn releases stop being offered for installation; rollback is offered only when runtime and save-schema compatibility permit it. Withdrawal of an asset/character version identifies every dependent official release and blocks new publication/distribution of affected versions pending owner review; it does not silently delete installed worlds or saved progress.
