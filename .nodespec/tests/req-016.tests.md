# Test Plan: REQ-016 - Asset Contract Automated Validator

## Testing Objectives

**Requirement:** Asset Contract Automated Validator
**Category:** technical
**Description:** The art-pipeline counterpart to the Level Contract checker, and the automated half of the two-stage art gate. Validates submitted assets against the Asset Contract on every pull request BEFORE a human maintainer spends time on art-direction review: correct file types, conforming resolution and format, valid alpha handling, correct directory placement and naming, and a present, schema-valid provenance.json. Structural conformance is machine-checked; style and art-direction judgment remains explicitly human. Like the level checker, it must be locally runnable and produce failures specific enough for a contributor or an AI agent to correct without guesswork.

## Project Context

OpenAxolotl — Play it. Fork it. Build a world.

A colorful 3D action-platformer in Godot where a tiny axolotl explores strange aquatic worlds, restoring damaged habitats and rescuing creatures. - **AC-REQ-016-2** [automated] [PENDING] Validator checks directory placement and naming convention conformance
- **AC-REQ-016-3** [automated] [PENDING] Validator requires a provenance.json per asset and validates it against the defined schema, failing on a missing or malformed one
- **AC-REQ-016-4** [automated] [PENDING] Failure output names the specific asset and the specific violated rule
