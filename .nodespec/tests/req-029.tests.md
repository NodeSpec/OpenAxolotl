# Test Plan: REQ-029 - Template Level — the on-ramp a new author opens

## Testing Objectives

**Requirement:** Template Level — the on-ramp a new author opens
**Category:** technical
**Description:** THE PROJECT'S TEACHING ARTIFACT, and the concrete answer to "families learn AI-development here." Not a curriculum and not a document: a level you can take apart. A newcomer opens it in Godot's own editor, plays it, changes something, and watches the change happen. That is the on-ramp, and everything else in the contribution story hangs off whether this level is actually openable by someone who has never seen the repo.

WHAT CHANGED, AND WHY. This started as a deliberately minimal fixture: five required contract elements, nothing optional, existing to prove the contract was satisfiable and that every optional element's absent-default really worked. That is a real job but it is a CI job, and it is the wrong shape for teaching — you cannot learn a game from an empty room, and a template that demonstrates nothing gives a newcomer nothing to change. That proof moves to `fixtures/worlds/conforming_world`, which already exists and is already exercised by the compliance checker, and the shipped template becomes the thing it is actually for.

WHAT IT HAS TO BE. Playable start to finish and small enough to hold in your head — minutes, not the acts an official world runs to. Built from a representative slice of the REAL game: the shipped axolotl, at least one Drift Fleet machine, water with the real shader, the shared lighting rig, a checkpoint, a collectible, and at least one mod-gated or restoration-gated path — so that every mechanic a newcomer might want to use is present once, as a worked example they can copy in place. Laid out and commented so the obvious first edits are obvious: move a platform, add a machine, drop in a collectible, retune a jump.

WHAT IT STILL HAS TO BE. It remains what a new level is COPIED from, so it must never drift out of conformance: validated by the compliance checker and the static-analysis gate on every pull request exactly like any other world, so a contract change that would break it fails CI rather than silently teaching the wrong pattern. Coral Cove and Bubble Bay are full official worlds and far too large to serve either purpose.

## Acceptance Criteria

Criterion text lives HERE once; every section below cites the AC id.

- **AC-REQ-029-1** [automated] [VERIFIED] The template implements all five required Level Contract elements: spawn point, checkpoints, finish condition, controller compatibility, save integration
- **AC-REQ-029-2** [automated] [VERIFIED] The template passes the Level Contract compliance checker as a required CI check
- **AC-REQ-029-3** [automated] [VERIFIED] The template passes the World Static Analysis Gate, calling only the sanctioned world API surface
- **AC-REQ-029-4** [automated] [VERIFIED] The hub discovers and loads the template like any other world, with no special case in loader code
- **AC-REQ-029-5** [automated] [VERIFIED] The template is completable from spawn to finish condition
- **AC-REQ-029-6** [automated] [VERIFIED] A contract change that would make the template non-conforming fails CI rather than passing silently
- **AC-REQ-029-7** [manual] [PENDING] The template is documented as the canonical starting point for a new world, with instructions on what to copy and what to change
- **AC-REQ-029-8** [automated] [PENDING] The template demonstrates each mechanic a new level is likely to use at least once as a worked example: both movement grammars, a checkpoint, a collectible, a Drift Fleet machine, water using the shared surface, the shared lighting rig, and one gated path
- **AC-REQ-029-9** [automated] [PENDING] The template is short enough to play in a few minutes and its scene tree is organised and commented so a newcomer can find and change a platform, a machine and a collectible without reading any core code
- **AC-REQ-029-10** [automated] [PENDING] A minimal world declaring no optional contract elements still loads and completes, proving every optional element's absent-default path, exercised by the conforming-world fixture rather than by the shipped template
- **AC-REQ-029-11** [manual] [PENDING] Someone who has not worked on this project opens the template in the Godot editor, makes a change of their own, and sees it in play without being told how by a maintainer
