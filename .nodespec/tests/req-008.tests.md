# Test Plan: REQ-008 - World Restoration State System

## Testing Objectives

**Requirement:** World Restoration State System
**Category:** functional
**Description:** Pillar 3 — the mechanic that carries the open-source metaphor without a child ever needing to get the metaphor. Regions within a world hold a first-class, inspectable restoration state with EXACTLY three states — barren, resourced, restored — plus a SEPARATE BOOLEAN UNLOCKED FLAG that gates whether progression may begin at all. The flag is deliberately not a fourth state: defeating a region's Flagship sets the flag, permitting a barren region to start progressing, while the state enum itself stays a simple three-step progression. The player collects a resource, restores water, plants bloom, wildlife appears, and new traversal paths open — so restoration is genuinely mechanical, gating progression and opening routes, not merely a cosmetic swap. Restoration state persists through the save system. It is also reversible under pressure: Dredger enemies flatten restored terrain back to barren, which gives the loop stakes and makes those encounters urgent.

## Acceptance Criteria

Criterion text lives HERE once; every section below cites the AC id.

- **AC-REQ-008-1** [automated] [PENDING] A region exposes a queryable restoration state with exactly the progression barren, resourced, restored, and a separate boolean unlocked flag
- **AC-REQ-008-2** [automated] [PENDING] A region whose unlocked flag is false cannot advance out of barren regardless of resources delivered
- **AC-REQ-008-3** [automated] [PENDING] Advancing restoration state changes traversable geometry or opens paths that were not previously available, not only visuals
- **AC-REQ-008-4** [automated] [PENDING] Restoration state and unlocked flag per region persist through the save-integration interface across sessions
- **AC-REQ-008-5** [automated] [PENDING] Dredger attacks revert a restored region to barren, and the reverted state is reflected in traversal and persistence
- **AC-REQ-008-6** [automated] [PENDING] Reverting a region to barren leaves its unlocked flag set, so restoration can be redone without refighting the Flagship
- **AC-REQ-008-7** [automated] [PENDING] A world declares its restorable regions declaratively through the Level Contract rather than through bespoke scripting
- **AC-REQ-008-8** [manual] [PENDING] The broken-to-restored transformation is visually dramatic and satisfying in hands-on play
