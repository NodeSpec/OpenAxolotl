# Test Plan: REQ-028 - Official World: Bubble Bay

## Testing Objectives

**Requirement:** Official World: Bubble Bay
**Category:** functional
**Description:** The second official MVP world, and the second half of the Level Contract battle-test. Where Coral Cove hosts the Flagship encounter, Bubble Bay deliberately ships WITHOUT a boss — that is not a scope cut but a deliberate proof that the contract's optional elements really are optional and that a world declaring no boss remains valid and completable. It must emphasize a different Gill Mod from Coral Cove so the two official worlds together exercise all three MVP mods. Like every world it is built exclusively through the sanctioned world API surface, with no private back doors an outside contributor could not use, verified by the same static-analysis gate community submissions face.

## Project Context

OpenAxolotl — Play it. Fork it. Build a world.

A colorful 3D action-platformer in Godot where a tiny axolotl explores strange aquatic worlds, restoring damaged habitats and rescuing creatures. Every world is a self-contained module anyone — human or AI coding agent — can fork, replace, or extend. Open source is a gameplay feature, not a line in the README.
