# Test Plan: REQ-018 - PC Build and Distribution

## Testing Objectives

**Requirement:** PC Build and Distribution
**Category:** technical
**Description:** A reproducible PC build of the game produced from the repository, plus the CI that proves the project stays buildable and playable as contributions land. PC-only is a firm non-goal boundary, not a staging step: no console certification is planned in any phase. The build must package the core game together with its official worlds, and the pipeline must run the Level Contract checker, the Asset Contract validator, and the automated test suite so that a contribution which breaks the game or violates either contract cannot merge. Because contributors and AI agents need a fast local loop, building and running from a clean clone must be a short, documented sequence.

## Project Context

OpenAxolotl — Play it. Fork it. Build a world.

A colorful 3D action-platformer in Godot where a tiny axolotl explores strange aquatic worlds, restoring damaged habitats and rescuing creatures. Every world is a self-contained module anyone — human or AI coding agent — can fork, replace, or extend. Open source is a gameplay feature, not a line in the README.

## Acceptance Criteria

Criterion text lives HERE once; every section below cites the AC id.

- **AC-REQ-018-1** [automated] [PENDING] A PC build is produced from a clean checkout via a single documented command
- **AC-REQ-018-2** [automated] [PENDING] The build packages the core game and all official worlds into a runnable artifact
- **AC-REQ-018-3** [automated] [PENDING] CI runs the Level Contract checker, the Asset Contract validator, and the automated test suite on every pull request
- **AC-REQ-018-4** [automated] [PENDING] A pull request failing any contract check or test cannot merge
- **AC-REQ-018-5** [automated] [PENDING] Building and running the game from a clean clone is documented as a reproducible sequence of at most five commands, and following that sequence verbatim produces a running game
- **AC-REQ-018-6** [manual] [PENDING] The packaged build launches and is playable end to end on a clean PC without a development environment installed
